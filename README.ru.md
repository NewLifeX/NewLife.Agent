NewLife.Agent устанавливает приложения .NET как системные демоны, объединяя службы Windows, systemd Linux и launchd macOS, с мониторингом, автоперезапуском и веб-панелью.

Tutorial: https://newlifex.com/core/agent

---
## Обзор

`NewLife.Agent` — сервис-ориентированный фреймворк для длительно работающих приложений. Он позволяет быстро размещать консольные/Web/Worker-программы как службы операционной системы и единообразно предоставляет установку, запуск/остановку, мониторинг, перезапуск и диагностику.

Поддерживаемые платформы:

- Windows (служба / автозапуск при входе)
- Linux (Systemd / Procd / RcInit и др.)
- macOS (LaunchAgent)

Поддерживаемые фреймворки:

- `NewLife.Agent`: `net40;net45;net461;netstandard2.0;netstandard2.1;net6.0;net7.0;net8.0;net9.0;net10.0;net11.0`
- `NewLife.Extensions.Hosting.AgentService`: `netcoreapp3.1;net5.0;net6.0;net7.0;net8.0;net9.0;net10.0;net11.0`

## Возможности

- **Разработка и эксплуатация вместе**: наследуйте `ServiceBase` и получите полный набор возможностей управления службой.
- **Встроенная веб-панель**: лёгкая панель управления для просмотра состояния и выполнения операций в браузере, с расширяемыми панелями и сменой темы, токен-аутентификацией и защитой от перебора; по умолчанию слушает localhost (`WebBind` позволяет открыть её в локальной сети), при первом запуске показывает локальную страницу настройки для задания пароля администратора (начальный файл пароля не создаётся; очистите `WebPassword` и перезапустите, чтобы снова открыть настройку), а для привязки по обычному HTTP к нелокальному адресу требуется `AllowInsecureRemote=true`.
- **Локализация на 31 языке**: встроенные команды, описания параметров, сообщения Hosting и веб-панель поддерживают 31 язык со сменой языка и RTL; язык запроса определяется NewLife.Core автоматически.
- **Кроссплатформенная адаптация**: автоматически выбирает подходящую реализацию хоста для каждой ОС.
- **Нативная публикация NativeAOT**: встроенные команды и веб-панель полностью адаптированы к trimming/AOT; сборки `net8.0+` не выдают предупреждений `IsAotCompatible`, а CI охватывает 12 RID: 9 целей проходят реальные smoke-тесты (8 нативных + linux-loongarch64 под эмуляцией QEMU в пользовательском режиме), для кросс-целей (linux-arm/linux-musl-arm/linux-musl-arm64) выполняется проверка публикации.
- **Многоархитектурные модульные тесты**: win-x64 / linux-x64 / linux-arm64 работают нативно, linux-loongarch64 (Loongson) прогоняет полный набор под эмуляцией QEMU в пользовательском режиме; запускаются по push/PR и вручную.
- **Встроенная система команд**: поддержка `-install/-start/-stop/-restart/-status/-run`.
- **Мониторинг здоровья и самовосстановление**: компонент HealthMonitor задаёт пороги памяти/потоков/дескрипторов, плановые перезапуски и проверки WatchDog.
- **Поддержка нескольких экземпляров**: разные значения `ServiceName` позволяют развернуть несколько экземпляров одной программы.
- **Пакет интеграции с Host**: включает приложения ASP.NET Core/Worker в единый жизненный цикл службы.

## Начало работы

### 1) Минимальная служба

Наследуйте `ServiceBase` и вызовите `Main(args)` в точке входа:

- Переопределите `StartWork(String reason)` для запуска бизнес-логики
- Переопределите `StopWork(String reason)` для остановки и освобождения ресурсов

### 2) Управление из командной строки

Основные команды:

- `-i`: установить службу
- `-install`: установить и запустить службу
- `-start`: запустить службу
- `-stop`: остановить службу
- `-restart`: перезапустить службу
- `-status`: показать состояние службы
- `-u`: удалить службу
- `-uninstall`: остановить и удалить службу
- `-run`: запуск в консольном режиме (для отладки)

> Установка/удаление/запуск/остановка обычно требуют прав администратора (Windows) или root (Linux).

### 3) Интеграция с ASP.NET Core / Worker

Подключите `NewLife.Extensions.Hosting.AgentService` и вызовите `UseAgentService()` в `HostBuilder`, чтобы связать жизненный цикл универсального хоста с управлением службами Agent.

## Быстрая установка

Добавить пакет в существующий проект:

```bash
dotnet add package NewLife.Agent
```

Или создать новый проект службы из шаблона:

```bash
dotnet new install NewLife.Templates
dotnet new service --name agent
cd agent
dotnet run
```
