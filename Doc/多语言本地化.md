# 多语言本地化

> 基线：NewLife.Core 12 编译期词表｜运行时 31 种语言、136 条后台消息（含 Hosting 扩展）与 116 条面板界面词条｜英文为源文与兜底

## 2. 词表文件

- `NewLife.Agent/Locales`：主库与 Hosting 扩展共用的运行时消息（Hosting 依赖主库，避免多程序集并发注册丢失词条）。

- 文件名即 BCP 47 语言代码；英文是源文与兜底，**不需要** `en.yml`。
- 键为**英文原文**，必须与代码字符串逐字一致（含空格与标点）；占位符 `{0}` 与格式说明符 `{1:n0}` 必须与英文一致。
- 词表由 NewLife.Core 包内的源生成器在编译期读取并生成压缩语言表，NativeAOT 下同样可用。

## 2.1 语言选择与请求语言

- `Setting.Language`（配置项 `Language`）显式指定界面与日志语言，如 `zh-Hans`、`fr`；为空时跟随操作系统。
- 保存配置后立即生效：`Setting.Save` 调用 `ApplyLanguage`，切换语言无需重启进程（菜单描述在显示时翻译，同样立即跟随）。
- 语言名无效或该语言没有词表时回退系统语言，并写一条警告日志，避免进程被锁在英文。
- 日志语言由 `Localization.LogCulture` 固定为宿主语言；Web 请求按 `Accept-Language` 切换的只是当前请求的 UI 文化，不会让日志跟着请求变化。
- Web 面板请求经 `RequestCultureScope` 按 `Accept-Language` 选择语言，响应带 `Vary: Accept-Language`；配置了 `Setting.Language` 时以配置为准。

## 3. 新增一条消息

1. 代码中写英文源文：`throw new XException("Session {0} is closed.", sessionId);`，日志直接写英文模板（`Logger.Format` 自动翻译）。
2. 在全部语言文件的同一位置补齐该键；遗漏只回退英文，不会编译失败。
3. 运行校验脚本确认键集合、占位符与格式说明符一致。

配置项描述同样以英文为源文写在 `Setting` 的 `Description` 特性中；`/api/ConfigMetadata` 按当前语言翻译描述，并取译文首句作为显示名，无需单独维护显示名词条。

保存 Xml/Ini 配置文件时，配置提供者按当前语言翻译注释，因此 `Agent.config` 里的 `<!--服务名-->` 等注释也跟随语言变化；缺少译文时保持英文原文（依赖 NewLife.Core 的配置注释本地化能力）。

命令处理器（`BaseCommandHandler`）的 `Description` 保存英文源文，`CommandFactory.GetShortcutMenu` 在生成菜单时翻译，因此切换语言后菜单立即跟随，不会在类型初始化时冻结。

## 3.1 Web 面板界面

面板 `index.html` 以**中文为源文**，`WebPanel/wwwroot/i18n/{语言}.json` 保存中文到目标语言的映射（一个键值对一条界面文案）：

- 服务端输出首页时按当前请求语言做**最长匹配替换**，命中 `<title>`、文本节点、`placeholder`/`title` 属性与脚本字符串；简体中文即源文，直接输出。
- 缺少对应语言文件时回退 `en.json`（英文），再缺词条时保留中文原文。
- 新增界面文案：先在 `index.html` 写中文，再在全部 `i18n/*.json` 补齐同名键；单元测试 `UiDictionaries_CompleteAndConsistent` 会校验各语言键集合与英文基准一致，并确认英文词表覆盖页面全部可见中文。

## 4. 带前缀日志

日志前缀（如 `[Agent]`、服务名）不参与本地化：先按日志语言翻译并格式化消息，再拼接前缀。

- 服务内：`WriteLogPrefixed("[Agent] ", "Service started: {0}", reason)`
- 任意 `ILog`：`log.WriteLogPrefixed(LogLevel.Info, "[Agent] ", "Service started: {0}", reason)`
- 与 NewLife.Core 的 `LogExtensions.WritePrefixed` 语义一致；net40 目标引用旧版 Core，由本库提供等价实现。

禁止写成 `WriteLog($"[{ServiceName}] 服务启动")`：整串查表必然回退英文，前缀也会被当成源文的一部分。

## 5. 校验

```powershell
pwsh -File check-locales.ps1 -LocaleDir NewLife.Agent/Locales -SourceDir .
```

CI 的 localization job 会遍历所有含 `Locales` 目录的项目并执行同一脚本。

面板界面词表由单元测试校验（`LocalizationTests.UiDictionaries_CompleteAndConsistent`），随 `dotnet test` 一起执行；新增或修改界面文案后运行该测试即可发现漏词条与多余键。
